### 这版修小窗：之前 430×780 被挤成一条竖缝

问题出在两处，都是看得见的错位：

- **剧场布局没摘干净**：`body.theater` 的 `.viewer{left:236px;right:14px}` 在小窗里还生效，430 宽的窗口被硬生生挤出 180 的画面区。实测 `stage=178x766`，而窗口是 `vw=430x780`。修法：进小窗时把 `theater` 类摘掉，CSS 再给小窗的 viewer 四边清零（`!important`）兜底。
- **窗口死固定 430×780**：片源 16:9（1280×720）塞进竖窗再 `cover`，只裁出中间 23% 宽的一条。修法：小窗窗口尺寸**跟着片源比例走** —— 横屏给 560×315 的横条，竖屏给 430×764 的竖条，`cover` 铺满刚好不裁人；尺寸记在 `hg_mini_size`，下次进小窗先按上次的来，片源加载完再校正，避免一进去先闪一下竖缝。
- **底部控件挤成四行**：`#vQual` 带内联 `display:flex`，原来的 `body.mini #vQual{display:none}` 被它压住，5 个清晰度按钮（360P 480P 540P 720P 1080P）全挤在小窗里。改成 `!important` 后小窗只留 ⏮ ▶ ⏭ / 选集 / ⛶ / 铺满 / 退出小窗 / 透明，一行排下。
- **窗口最小尺寸卡住高度**：进小窗时 `MinimumSize` 是 300×420，横屏要的 315 高被拦下，窗口永远退不回矮条。改成 260×200。

实测（`--mini --dbg`）：

```
进入小窗模式 430x780
小窗适配画面 560x315
mini vw=560x315 dpr=1 stage=560x315 video=1280x720 fit=cover
```

窗口、视口、画面三者对齐，16:9 铺满无裁剪。形态互切仍是 `560×315 → 1920×1080 → 560×315 → 删小窗` 不掉尺寸。
