# v1.017 — 版本推送 & 仓库主页

2026-11-23

这一版没有新功能加进来，做的是"把东西递到你手上"的两件事：程序自己知道该不该更新，仓库有了一页能看的主页。

## 一、版本推送

程序里从此有了自己的版本号，也知道了外面有没有更好的。

- 本地版本写在 `ui/version.txt`（一行，比如 `1.017`），打包时随包走
- 远端版本在仓库根目录 `version.json`，就五个字段：

```json
{
  "version": "1.017",
  "tag": "v1.017",
  "date": "2026-11-23",
  "url": "https://github.com/guhang42-jpg/hongguo-desktop-skin/releases/tag/v1.017",
  "notes": "新增版本推送与仓库主页"
}
```

流程是这样：

1. 界面起来 12 秒后再去问（不跟启动抢资源，你也不会看见一个卡住的开屏）
2. 拉 `https://raw.githubusercontent.com/.../main/version.json`，十几 KB，超时 12 秒
3. 比版本号（逐段数字比较，`1.017 > 1.016`）
4. 有新的：顶部那颗胶囊换成 **「新版 v1.017 出来了 · 点这里看看」**，边框挑成暖橙、能点，停 9 秒；托盘同时冒一个气泡，点气泡也是打开同一个页面
5. 没新的：什么都不做，只在日志里留一行「已是最新 1.016」
6. 托盘右键菜单多了 **检查更新**，手动查的时候会在托盘回你一句「已经是最新版」或「没连上」

**只放行 GitHub 的 https 链接。** 界面里任何东西想让程序开浏览器，URL 不是 `https://github.com/` 开头的一律拒绝并记日志——不给界面留一个"能借我的手开任意程序"的口子。
`--noupd` 关掉整套检查（离线机器、公司网络拦 raw 域名的时候用）。

### 关于"不联网"这四个字

这是本程序**唯一**的一处外连：只 GET 一个几 KB 的 JSON，不上传任何本机数据，不带你看了什么剧、记了什么偏好，也不统计。不想要就 `--noupd`，或者干脆删掉 `ui/version.txt`——没有本地版本号时它会静默跳过比对（`0.0.0` 只用于日志）。

## 二、仓库主页

`docs/index.html`，一页式，深色玻璃风，直接对上程序里那套界面语言：

- 顶部氛围光 + 毛玻璃导航条 + 版本徽章
- 一行大字说清这玩意儿是什么，两个按钮：下载最新版 / 看源码
- 截图墙（发现页、一键摸鱼、小果记忆、按偏好找剧），图都是真机截的，不是效果图
- 能力分四块：界面 / 播放 / 小果 / 摸鱼
- 版本时间线，每个版本一句话
- 底部一行免责声明与回仓库的链接

所有图都是相对路径，走 GitHub Pages 时零配置。

## 三、两个真 bug（都是"看着能用、其实不能用"）

**① 检查更新一条日志都没有。**
第一次真机测：跑满 40 秒，`app.log` 里连"检查更新超时"都没写。原因是网络异常时 `DownloadString` 抛异常 → `body` 仍是 `null` → 代码 `if (body == null) return;` 直接静默返回，异常信息丢了。修法：异常先存进 `err`，拿不到内容时如实写日志"检查更新拿不到内容：xxx"；同时 `ServicePointManager.SecurityProtocol` 先抬到 TLS 1.1/1.2（.NET Framework 的 WebClient 默认可能只到 1.0，而 raw.githubusercontent.com 只收 1.2+），系统代理不通时再绕开代理直连重试一次。
修完：启动后第 12 秒准时出现「检查更新（当前 1.016）」，1 秒后「发现新版本 1.017」。

**② 胶囊看得见，点不动。**
`.toast` 基础样式里有 `pointer-events:none`（普通提示本来就不该挡住点击），而 `.toast.upd` 只补了 `cursor:pointer`，没把事件放开——鼠标移上去变手型，点下去什么也不发生，最容易骗过测试。补 `pointer-events:auto` 之后真机点一下，日志立刻出现「打开链接 https://github.com/.../releases/tag/v1.017」。

## 实测（本机 2026-11-23）

| 场景 | 结果 |
| --- | --- |
| 本地 1.016 / 远端 1.017 | `检查更新（当前 1.016）` → `发现新版本 1.017（当前 1.016）`，1 秒 |
| 顶部胶囊 | 「新版 v1.017 出来了 · 点这里看看」，暖橙边框，停 9 秒，鼠标变手型 |
| 点胶囊 | `打开链接 https://github.com/guhang42-jpg/hongguo-desktop-skin/releases/tag/v1.017` |
| 托盘气泡 | 同一时刻冒「有新版本 v1.017」，点气泡走同一条 openUrl |
| 本地 = 远端 | 只写 `已是最新`，界面一动不动 |
| 非 GitHub 链接 | 拒绝并记日志 |
| `--noupd` | 整套不执行，启动日志无任何更新字样 |
| 主页 | Edge 打开无报错，四张图全部加载，时间线到 v1.017 |
