# v1.016 · 记忆能拿出来看，找剧真按你记的来

> 三件事：**记忆落成可打开的文件**、**「推荐一部」这种空话按你记的偏好去挑**、**你不来找的时候她会自己吭一声**。

## 一、记忆落成可打开的文件

以前记忆只活在 WebView2 的 localStorage 里，看不见摸不着。这版多写两份到磁盘：

```
%APPDATA%\HonggoDesktop\xiaoguo-memory.md      ← 给你看的，人话版本
%APPDATA%\HonggoDesktop\xiaoguo-memory.json    ← 给程序回的，原样数据
```

那份 md 长这样：

```markdown
# 小果记得的事
- 见过：7 回　聊过 8 次（今天 1 次）
- 亲密度：70 / 100
- 第一次来：2026/11/3 06:41:53

## 你自己说过的偏好
- **爱看修仙的**　·　2026/11/22 06:41:53　·　提过 3 次
- **不喜欢太长的**　·　2026/11/23 04:41:53

## 最近问过的
- 「推荐一部」　·　2026/11/23 06:44:10
```

- **localStorage 还是主存储**，文件是快照，每次变化后 **1.2 秒去抖**写一次，不狂写盘
- 走 **base64** 过宿主桥（省得在 C# 里跟 JSON 转义较劲），中文不乱码
- 启动时如果本地存储是空的，就从 json **兜底恢复** —— 实测：把浏览器存储清掉再开，日志回「记忆文件兜底恢复成功：2 条偏好 · 见过 7」，开场白照旧是「你上次停在《徒儿对不起，功法是我瞎编的》第 98 集，还剩 28 集」
- md **是给你看的快照，手改不生效**（别骗自己）。想让它忘干净，在面板里说一句「忘了吧」比改文件可靠；json 才是能回灌的那份

## 二、找剧真按你记的来

以前「推荐一部」「随便来部」「有没有好看的」这类话，等于没信息，走的是官方推荐池，跟你的偏好一点关系没有。

这版先剥泛词（推荐 / 来一部 / 随便 / 好看 / 点啥 …），**剥完什么都不剩才承认这是句空话**，然后：

1. 从记下的偏好里挑一条最该用的（次数多、最近说过的优先，否定的偏好不当种子）
2. 把「爱看修仙的」剥成 **`修仙`** 当语义种子 —— 这个 `topic` 在记账时就一起存下来了，不用每次重新猜
3. 记过「不喜欢太长的」→ 结果**真的按集数升序挑**

实测一句话：

> 你跟我说过「爱看修仙的」，就照记的挑短一点的：
> 按记忆找的 · 本机语义 · 库内 1130 部
> 《真，脑洞修仙传》16 集 · 短的 / 《模拟修仙》33 集 · 短的 / 《我自创功法修仙》71 集 · 短的

没记过偏好的人才回到原来的推荐池。**记了就得用上，不然等于骗人。**

## 三、你不来找的时候，她会吭一声

窗口最小化、你干别的活去了 —— 小果现在能在托盘上说一句。

- **托盘**：图标 + 右键菜单（打开小果 / 随便挑一部 / 今天别打扰我 / 退出），双击直接唤回窗口
- **到点看一眼**：每 **45 分钟**醒一次，只比内存和记忆文件里的几个时间戳 —— **不截屏、不联网、不调模型、不读你的屏幕**，醒完就睡
- **规矩**：8:00–22:00 之外一句话都不说；**一天最多一句**；摸鱼态、全屏看片中、小窗挂机一律不打扰
- **三个话头**（按顺序）：
  - 隔 ≥3 天没开 → 「你有 **N** 天没来了。想挑一部看看吗？」
  - 记过偏好 → 「你说过爱看「**修仙**」。我给你挑一部？」
  - 都没有 → 「今天还没见你说话。要不要找部短的看看？」
- **点气泡**：窗口起来 + 小果自动问一句「推荐一部」→ 直接出卡，不用你再打字
- 「今天别打扰我」只静音到**明天 8 点**自动恢复，不会一次手滑变成永久失联
- 点右上角 X 仍然是**真退出**，不留后台进程；不想要托盘可以 `--notray` 完全关掉

## 实测

| 场景 | 结果 |
|---|---|
| `--ai --mem --noa` 开面板 | `xiaoguo-memory.md` 581 B / `.json` 397 B 落盘，格式如上 |
| 清掉 localStorage 再开（`--memfile`） | 日志 `记忆文件兜底恢复成功：2 条偏好 · 见过 7`，开场白完整 |
| 「推荐一部」 | 走记忆路径，三部按 16 / 33 / 71 集升序，标签「短的」 |
| `--poke` 立刻走一次 | 日志 `主动出声: 你有 3 天没来了。想挑一部看看吗？` |
| 托盘与定时器 | 日志 `托盘就位` / `到点检查已开：45 分钟一次，8:00–22:00，一天最多一句` |

## 联调参数（这版新加的）

- `--notray`：不起托盘、不主动出声
- `--poke`：起来立刻强制走一次「到点看一眼」，跳过时间窗与"今天已说"，保留摸鱼 / 全屏 / 小窗的判断
- `--memfile`：启动先清掉浏览器存储里的记忆，逼它只靠文件兜底

## 这版没做

- **X 关闭仍是真退出**，不做后台常驻（"低功耗"这条底线守住，托盘只在程序活着时存在）
- md 手改不生效，只往下写不往上读（回灌只认 json）
- 主动出声不读 core 的续播数据，所以它不会在气泡里说「《X》还剩 N 集」—— 只用记忆里的时间戳和偏好
- 记忆容量还是偏好 24 条 / 提问 24 条，没有按时间衰减
