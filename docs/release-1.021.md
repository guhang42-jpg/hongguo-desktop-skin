# v1.021 —— 播放页和详情页那两条竖栏，也收成图标

一句话：主界面的折叠抽屉做完了，这次把播放页左侧（返回＋竖排剧名＋集数）和详情页左侧（播放/收藏/追更/关闭）一起换成同一套图标抽屉，全项目只剩一种侧栏语言。

## 改了什么

**播放页**（`.vtop`）

- 从 96px 全高竖排区收到 **58px**：折叠态只剩左上角一枚 36px 返回圆钮，画面左边缘干净了 38px
- 鼠标移到这条上，`58 → 214` 铺开成玻璃抽屉（右侧 18 圆角 + 外投影），`剧名` 一行省略号、`第 N 集` 暖橙小字在下面 —— 原来那个把标题竖着码成 1.7em 一行一个字、集数还要靠负 margin 硬拗位置的做法整个删掉
- 剧名文字不再是裁出来的，`opacity 0 + translateX(-6px)` → hover 归位
- 剧场模式（`body.theater`）与全屏（`body.fs`）沿用同一套尺寸；`idle` 隐藏规则不变

**详情页**（`.srail`）

- 从 80px 竖排卡堆（每张 76px 高、图标上文字下）收到 **58px** 图标条：`▶ / ♡ / 🔔 / ✕`，每格 46×46
- 悬停铺开到 **156px**，图标左移、文字从右边浮出（播放 / 收藏 / 追更 / 关闭），文字宽度不再是 `1em` 加 `word-break:break-all` 那张竖排补丁
- 关键结构改动：`.srail` 改成 `position:absolute` 浮在面板左侧，`.smain{margin-left:58px}` 让内容固定从图标条右侧起算 —— **展开时不挤压右侧内容**，只盖住自己那 98px
- 面板宽度 `556 → 580`，补回图标条省下的 22px 都给正文
- 收藏按钮的图标仍是 `<i>♥/♡</i>` 文本节点，没换 SVG —— 因为 `app.js` 直接往 `querySelector("i")` 写字符，换 SVG 会把图标洗掉

## 顺手修的

- 详情简介 `.sdesc` 的 `max-height` 从 98 提到 112，原来刚好切在半行字上，看着像"选集"标题压着正文

## 验证

真机 `PrintWindow` 四张：

1. 详情页折叠 → 58px 图标条，内容从 838px 起，正文完整
2. 详情页悬停 → 156px 抽屉，四个按钮文字全出，右侧封面与选集未位移
3. 播放页折叠 → 1920×1080 全屏，左上角只有一枚返回钮
4. 播放页悬停 → 214px 抽屉，`徒儿对不起，功法是我起…` + `第 1 集`，视频正常播放（这条片源本机能解码）

## 还留着的边界

- 播放页与详情页的抽屉都是浮层，展开时会盖住画面/封面左边缘（播放 214px、详情 98px），移开即恢复。播放页尤其明显，但全屏看片时鼠标不动会自动隐藏（`idle`），实际干扰很小。
- 播放页剧名在 190px 内走省略号，超长标题只能看见前半段。
- 详情页图标条在 `mini` 小窗下不显示（`body.mini .sheet` 整体隐藏），逻辑未变。
