### 这版只干一件事：修「换电脑装上有声音、没画面」

片源是 H.265（bytevc1）。WebView2 自己不会解 H.265，得交给 Windows 的 Media Foundation；机器上没装 HEVC 扩展，就只有声音、画面全黑——这不是皮肤的小毛病，是那台电脑缺解码器。

- **启动就自检**：用 `canPlayType` 探 `hvc1/hev1`，缺了解码器直接在顶上顶一条提示，写明「缺 HEVC 解码器」。
- **一键去装**：提示条上的「去安装」直接拉起微软商店的 `HEVC Video Extensions`（￥0 的设备制造商版）页面，不用自己去搜——这个包在商店里搜名字是搜不到的。装完点「装好了，重启」，应用自己重启（解码器只在进程启动时加载）。
- **内核开关也打开**：给 WebView2 传 `--enable-features=PlatformHEVCDecoderSupport`，修的是另一种情况——装了扩展，但内核没启用平台解码，照样黑屏。
- **播到一半才发现没画面的**也有兜底：`videoWidth` 一直是 0 就判定「有声音没画面」，再把提示条顶上来并 toast 一次。

装好扩展后那台机器之前的所有功能（续播、多季、选集分段、榜单徽标、倍速音量）都能正常用，不用再折腾别的。

### 换电脑要用的话，按这个顺序

1. 解压到任意目录，双击 `红果短剧.exe`。
2. 顶上出现橙色提示条 → 点「去安装」→ 商店点「获取」装完。
3. 回来点「装好了，重启」。

提示条关掉后会记在本地（`hg_hevc_dismiss`），下次启动不再烦你；真播不出画面时还是会再弹一次。
