# 红果短剧・桌面皮肤版 v1.014 — 小果开始"听懂"人话

上一版它学会了按意思找剧。这一版它学会了**先判断你在说哪件事** —— 你换个从没说过的说法，它也能接住，而不是把那句中文当成剧名扔进搜索框。

![](https://raw.githubusercontent.com/guhang42-jpg/hongguo-desktop-skin/main/docs/preview-intent.jpg)

「我上次停在哪集了」这句话里没有"看到哪"、也没有"追到哪"，原来的 10 条正则一条都不匹配，它会把这句话当剧名去搜，然后告诉你"没搜到"。现在它会认出这是问进度，直接答《徒儿对不起，功法是我瞎编的》第 98 集，还差 29 集。

## 怎么做的

同一套 24 MB 的模型，多做一件事：给 9 类意图各准备十几条不同说法（共 122 条），全部算成向量存在 `ui/ai/intents.bin`（122 KB）。你开口时，把你的话也编码成向量，跟这 122 条比一遍，看最近的是哪一类。

阈值是实测扫出来的 —— **分数 ≥ 0.40 且领先第二名 ≥ 0.10 才动手**，不然就退回原来的找剧流程。

几个关键取舍：

- **用最近邻，不用均值原型。** 第一版给每类取了平均向量，看起来更"规整"，实测召回掉到一半 —— 平均会把"我上次看到哪了"和"上次停在哪集了"这两种说法之间的差异抹平。改成保留全部 122 条原句后，召回从 7/13 升到 10/13。
- **必须先中心化。** 不减去全体例句均值的话，9 类原型两两余弦全在 0.75–0.88，聊什么都像聊同一件事。中心化后彼此落到 -0.4~0.17，才分得开。
- **只认 6 类，其余一律放行。** resume / fav / stats / help / short / recommend 这 6 件事判错了答得离谱，所以设门槛；而 search / play / detail 判出来也**不派发** —— 找剧本来就是默认出口，不需要让模型来回答"这句话是不是找剧"这种它天然有偏的问题（实测"找都市题材的"会被它当成"来部短的"）。

## 实测

13 条**从没进过例句集**的说法：

```
我上次停在哪集了        → resume   0.510 / 0.179  ✓
我昨天看的到第几集了    → resume   0.919 / 0.464  ✓
我标记的那些剧呢        → fav      0.524 / 0.190  ✓
我这一周追了多少集      → stats    0.555 / 0.425  ✓
你能做哪些事            → help     0.801 / 0.774  ✓
给我来部短的            → short    0.753 / 0.437  ✓
有没有特别短的一晚上看完 → short    0.645 / 0.324  ✓
有什么值得看的          → recommend 0.435 / 0.122 ✓
```

12 条陌生**找剧**话（这些必须不被抢走）：

```
有没有讲小偷的              → search 0.300 / 0.140  放行
我想看那种主角一开始被冤枉的 → search 0.311 / 0.148  放行
来部讲医院故事的            → search 0.438 / 0.024  间隔不够，放行
想看那种大女主宅斗          → search 0.432 / 0.236  放行
有没有讲赛车或者拳击的      → search 0.259 / 0.102  放行
…（12 条全部零误判）
```

**误判 0/12，召回 10/13。** 漏掉的那 3 条会回到找剧流程，不答错，只是没享受到这层能力。

## 门槛的扫法

| 分数下限 | 间隔下限 | 强意图召回 | 找剧误判 |
|---|---|---|---|
| 0.35 | 0.10 | 10/13 | 0/12 |
| **0.40** | **0.10** | **10/13** | **0/12** |
| 0.45 | 0.10 | 9/13 | 0/12 |
| 0.40 | 0.15 | 9/13 | 0/12 |

0.35–0.40 是一样的分数，取 0.40 留点余量。宁可漏判，不能错判。

## 两个包

| | 大小 | 差在哪 |
|---|---|---|
| `hongguo-skin-1.014-win64.zip` | 6.9 MB | 只有正则，换个说法就得靠运气 |
| `hongguo-skin-1.014-win64-ai.zip` | 25 MB | 多了 `ui/ai/`，会按意思找剧 + 认意图 |

轻量包没这个目录就完全不启动，**不报错、不吃内存**。
