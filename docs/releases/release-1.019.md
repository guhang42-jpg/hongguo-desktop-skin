# v1.019 —— 左边那条栏，收起来了

一句话：左侧导航从 104px 的竖排文字栏，变成 68px 的纯图标窄条；鼠标移上去自己铺开成 200px 的抽屉，带文字和账号卡；移开自己收回去。

## 改了什么

原来那一列是「竖排一个字一个字码」的导航：红果、发现、找剧、榜单、我的，外加底部一张账号卡。占 104px，可读性全靠竖着念，屏幕上永远有一块面积只为放这几句话。

现在：

- **宽度 104 → 68**，`--railw` 改一个值，`.app` 的栅格第一列跟着变，剧场模式的 `left` 也跟着变，内容区一下多出 36px
- 栏里只留**图标**：logo、四个线性图标（罗盘 / 放大镜 / 柱状 / 人像）、小果那颗球、底部头像，全部对准同一条竖线（中心 x=34）
- 鼠标进来（`.side:hover`），内层 `.sideIn` 从 68 过渡到 196，玻璃底从透明淡入 `rgba(15,17,24,.74)` + `blur(22px)`，右侧 20px 圆角、外投阴影 —— 变成一张压在内容上的抽屉
- 文字（红果 / DESKTOP / 发现 / 找剧 / 榜单 / 我的 / 账号名 / Lv）不是靠裁切露出来的，是**各自淡入 + 从左 6px 位移归位**，跟宽度过渡错开一点时间，看起来像"铺开的同时字浮上来"
- 抽屉是**绝对定位浮在内容之上**，不推挤主内容，鼠标一移开就退回 68，看片时不会因为瞄一眼侧栏而整页跳一下
- 账号卡改成 `38px | 1fr | auto` 的网格，名字过长走省略号（`用户46970…`），不会再把 Lv 胶囊挤到字上面去

## 连带的两个修正

- **小果的面板位置**：球左移之后，气泡按原来的"球左侧减 10"定位会从 x=-2 起，整块压住侧栏。改成从球右侧 +8 起，并夹到窗口内（`Math.min(b.right + 8, window.innerWidth - 352)`），气泡现在贴着窄条右边长出来
- **选中态**：竖排时代那个"字下面一个小圆点"没意义了，去掉。选中项改成整行橙色渐变块（折叠态是 56px 宽的圆角小方框，展开态铺满 176px），左边缘那条竖指示条也一并撤掉 —— 只留一块底色，够了

## 验证

三次真窗口截图（`PrintWindow`，1360×880）：

1. 鼠标停在内容区 → 68px 窄条：logo、四个图标、球、头像都在，没有任何文字
2. 鼠标移到栏内 y=250（榜单那一行）→ 铺开到 196px：图标 + 文字 + 账号卡全露，榜单行有 hover 底
3. 鼠标移回内容区 → 一秒内退回 68px，主内容没有位移

顺手把球的位置对了一遍：折叠态 8..60（中心 34），和 logo（15..53，中心 34）、图标（中心 34）、头像（15..53，中心 34）在同一条线上。

## 还留着的边界

- 展开态是浮层，会临时压住主内容左侧 128px（推荐/漫剧/真人剧那几个标签会被挡一截），鼠标移开即恢复。这是抽屉式交互的代价，没有改成推挤布局，因为推挤会让看片时整页横跳。
- 播放页左侧那条竖栏（返回 + 竖排剧名 + 集数）还是老样子，这次没动。
- 滚动条、搜索框、顶部标签的位置都没变，只是整体左移了 36px。
