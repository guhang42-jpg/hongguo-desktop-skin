### 这版主要动的是播放器

- **播完直接接下一集**，没有读秒倒计时了。原来那个「5 秒后播放第 N 集」的浮层整段删掉，一集结束立刻原地换源，画面不退回面板、不闪海报。
- **打开即全屏**：点播放 0.2 秒后自动进真全屏，画面默认「铺满裁剪」，左右没黑边。你手动改过画面模式（原比例 / 拉伸），之后就按你改的来。
- **每集都从头开始**：换集先把旧源卸干净再归零，不再出现「新一集一开场就播完」。三集连播实测 `t0 = 0.00`。
- **续播记忆**：同一集看到一半退出，下次点这集接着上次的位置，详情页那颗播放键会写「继续看 00:15」。自动接下一集不吃这套，永远从头。
- **倍速与音量**：`1.0× / 1.25× / 1.5× / 2× / 0.75×` 循环（`R`）；音量做成了滑条，点喇叭弹出、拖完记住，滚轮也能调，`M` 静音。都记住上次的选择。
- **小窗 ↔ 全屏互切修好了**：两种窗口形态互斥，小窗进全屏会先收小窗，退出全屏退回小窗；全屏进小窗也不会把尺寸拧成奇怪的中间值。实测轨迹 `430×780 → 1920×1080 → 430×780 → 1360×880`。
- **顶部「弹幕 开」按钮拿掉**了，改按 `D` 切换，弹幕不再挡视线。
- 顺手修掉换集瞬间误亮的白色暂停圆。

### 界面：短一点、细一点

- **首页折叠**：热播榜默认收起、推荐区只露两行，点了才展开；找剧 / 榜单 / 我的页不再摆 Hero 和两条横滑，页面短了一半。
- **找剧细化**：排序（推荐 / 热度 / 口碑 / 集数少 / 集数多）、集数段（≤40 / 41–80 / 80+）、题材标签（从已加载剧集里统计出的热门前 10，点一下就能筛）。
- **榜单细化**：一级「综合榜 / 真人剧榜 / 漫剧榜 / 官方推荐榜」，二级「官方推荐序 / 最热播 / 口碑高 / 短剧精选 / 长剧专场」。卡片左上角有名次牌，前三名是金 / 银 / 铜；跟上次打开这个榜时的顺序比对，真涨真跌才显示 `↑2` `↓1`，没数据不编。
- **详情页多季切换**：同一部剧的第 1..N 季横排，点了直接换季（封面、简介、集数全跟着换）；还没上线的续季灰着，点了只提示等更新。
- **选集按 10 集分段**：`1-10 / 11-20 / 21-30 …`，80 集 96 集的长剧不再一次铺几十个按钮，看过的集标成暖色。

### 一个技术上的调整

WebView2 的 localStorage 是按 origin 隔离的，而官方 core 默认在随机端口上起服务 —— 端口一变等于换了存储，续播点、音量、倍速全丢。所以外壳现在固定让 core 监听 `18797`（避开官方的 8797）；万一这个端口被占，会自动回退成随机端口，功能不受影响，只是这次开机不保留本地记忆。

### 已知限制

- 非官方第三方界面，官方换接口就得等跟进
- 播放依赖官方核心，第一次启动会多一个后台进程，那是官方的，别误杀
- 4K / 杜比这类档位官方没有，自然也没有
