# v1.020 —— 把那条抽屉磨细

一句话：抽屉还是那个抽屉，但划过不再乱弹、展开后字更实、小窗形态不硬铺开、收起时少掉帧。

## 改了什么

- **随手划过不再弹一下**：`transition-delay .1s` 只加在收起方向，展开仍是零延迟立刻出。鼠标沿着侧栏边缘往内容区划一下，抽屉要等 100ms 才动，够它判断你只是路过。
- **展开态底色变实**：`.72/.82` 提到 `.945/.965`。原来太透，背后 hero 的 `正在热播` 胶囊、`全 301 集` 会透过抽屉跟导航文字叠在一起，看着脏；现在只有 blur 边缘还有一点呼吸感。
- **brand 两行给 3px 行距**：`红果` / `DESKTOP` 之前贴得太紧，字号一大就糊成一块。
- **小窗（mini）形态禁展开**：窗口只有 430 宽时，铺开 196 会把内容盖掉一半以上。现在 `body.mini` 下 hover 不再变宽，图标照旧亮一下，文字强制 `opacity:0`，等于小窗里它就是一条纯图标栏。
- **`backdrop-filter` 退出过渡列表**：不再每一帧重算 20px 模糊，只在展开态一次性应用。同时外投阴影 `26px 0 54px -24px` 收到 `18px 0 44px -22px`，模糊 22→20 —— 展开那 340ms 少掉一轮逐帧重绘，老机器上卡顿感明显轻。
- **图标 hover 上浮 1px**：`scale(1.08)` 改成 `translateY(-1px) scale(1.06)`，鼠标扫过四个图标时是"抬一下"而不是"胀一下"，跟抽屉铺开的纵向动势一致。

## 验证

真窗口 `PrintWindow`，1360×880，四张：

1. 鼠标停在内容区 → 68px 窄条，无文字
2. 鼠标移到侧栏内 → 196px 抽屉，字清楚、背后内容不再穿透
3. 移开 300ms → 抽屉仍保持（100ms 延迟 + 340ms 过渡，此刻在收的中段）
4. 移开 700ms → 完全退回 68px，主内容零位移
