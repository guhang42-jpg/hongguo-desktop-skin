# v1.027 — 长剧段按钮换行、图标收口、圆钮热区与气泡朝向、成就墙收窄

这版是 v1.026 那套界面的「收尾打磨」，五处都是上一版留下的小别扭，不起新功能、不动播放链路。

## 改了什么

**1. 长剧的段按钮行：横向滚动条撤掉，改成换行**

711 集、301 集这种长剧，选集上方的「1-24 / 25-48 / …」段按钮原来是一行排到底、横向滚动。问题是那根滚动条正好压在最下面一排按钮的底边上，滚动条细得像条划痕，还挡着点。

- `.epsegs` 从 `overflow-x:auto` 改成 `flex-wrap:wrap`，`gap` 8×6
- 段落间距收紧一点：高 30 → 28，左右内边距 12 → 10，字号 12 → 11.5
- 结果：126 集 6 段仍是一行；301 集 13 段自然折成两行（8 + 5），没有滚动条；711 集同理

**2. 顶栏三颗字符图标换成矢量**

刷新原来是 `⟳`，账号原来是 `◍`，跟齿轮那颗线性 SVG 摆在一起，粗细、留白、圆心都不对。这版统一成同一套：

- 刷新 → rotate-cw（圆弧 + 箭头尾，线宽 1.7）
- 账号 → user（头部圆 + 肩线）
- 齿轮不动（Feather settings 八齿）
- 新增 `.ic svg{width:16px;height:16px;display:block;pointer-events:none}`，三颗的视觉重量、对齐一次性对齐

**3. 圆钮：可见尺寸不变，热区外扩 6px**

28px 是看着舒服的尺寸，但鼠标真要「点中」它，得精确落在那一小圈里。这版不加视觉，只加透明热区：

- `.sec .tb` 加 `position:relative`，`::after` 撑成 `inset:-6px` 的透明圆
- 视觉仍是 28px 一圈，实际可点区域 40px，和左侧栏图标、顶栏三钮的手感一致
- 实测：点在圆钮中心外 17px（视觉圆外、热区内）也能正确折叠

**4. 圆钮的气泡改朝上弹**

自绘提示原来是「鼠标下方 18px」，挂在标题行右侧时会压住下一行卡片，遮住封面的一角。这版按触发点分方向：

- 触发点是 `.tb` 圆钮时，气泡默认排在钮的**正上方**（`y - h - 16`），上方真放不下才回落到下方
- 标题行在卡片上方，气泡朝上就落在 Hero 静态大图或页面留白上，不再压任何内容
- 其他触发点（卡片、行项、格子）行为不变

**5. 成就墙：默认只露「已解锁 + 3 个最接近的」**

45 项的成就墙原来要么全铺（占三屏）、要么粗暴截断到 16 格。这版改成有选择的收：

- 折叠态 = 已解锁项（按解锁时间**倒序**，最近拿到的排最前）+ 未解锁项按定义顺序取前 3 个（也就是最容易拿的）
- 计数位改成 `28 / 45　还有 17 项未解锁`，数字对得上（28 + 17 = 45）

- 右上那颗折叠钮由原来的文字按钮「展开全部 / 收起」换成 `.tb` 圆钮 + chevron，展开态箭头朝上，折叠态朝下，`data-hint` 随状态变
- 展开后仍铺全部 45 项，位置不变

## 顺手修的

- `.achgrid.fold .ach:nth-child(n+17){display:none}` 这条 v1.026 的旧兜底还在，会把手动渲染的 31 格又砍回 16 格 —— 删掉，兜底放宽到 `n+64`
- 成就计数原写「还有 M 项待解锁」（M = 未解锁数减 3），和左边的 `28 / 45` 一对读会觉得 28 + 14 ≠ 45 —— 改成未解锁总数，自洽

## 已知边界

- 段按钮换行会让长剧详情页的选集区整体下移半行到一行，110 集位置随之微调
- 圆钮热区靠透明 `::after` 实现，两枚圆钮挨得近时（同一行左右各一颗，如「热播榜」那行的收起与 ›）热区不重叠，中间仍留有缝
- 气泡朝上只在 `.tb` 触发点生效；其他触发点保持朝下
- 不联网、不调模型、不截屏、不起后台服务；外壳 exe 与 v1.026 是同一个

## 安装

下载对应压缩包，解压到任意目录，双击 `红果短剧.exe`。首启会在 `%APPDATA%\HonggoDesktop` 起本地数据目录；保留旧目录即为升级。语义版多带 10 个模型文件，放 `ui\ai\` 下，小果会自己用。
