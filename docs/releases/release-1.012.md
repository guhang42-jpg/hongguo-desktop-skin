# v1.012 — 小果对话框：玻璃、气泡、无痕迹

这一版只改小果那一块的外观和手感，功能、包体、启动方式都没动，仍是 8 个文件、解压即用。

## 玻璃

上一版是一块实底深灰渐变 + 1px 描边，看着像贴了张不透明的卡片。这版换成真玻璃：

- 底色从 90% 不透明度降到 74%，背后加 42px 模糊 —— 首页的海报墙不再被完全挡住，变成了透过毛玻璃的一层色雾
- 描边整条去掉，改用两层内阴影：上缘一条极细的亮边、下缘一层渐暗。这样"玻璃的厚度"能看出来，但看不到任何一条硬线
- 面板内部再压一层上下渐变（顶部微亮、底部微暗），像从侧面看一块厚玻璃的截面

## 气泡

消息从"方角灰块"改成左右对话气泡：

- 送话在右、橙色；小果在左、灰色。两边各带一个朝向说话人的尖角，内侧那个角收小，读起来就是一条从嘴里出来的话
- 气泡本身**不再单独做背景模糊**。这是刻意的：尾巴和气泡都只是同一个半透明色，两者零重叠、同色同透明度，落在同一片背景上，所以放大 4 倍也找不到接缝。如果给气泡单独加模糊，尾巴采样的是没被模糊的背景，接缝立刻显形
- 每条小果消息左边有一个 20px 的头像点，消息进场是 8px 上浮 + 淡入

## 无痕迹

- 消息区上下两端用 mask 渐隐：滚到边上的气泡不是被硬切一半，而是化进面板
- 头部分隔线、输入区分隔线都改成"两端消失"的渐变线，中间实、两头虚
- 滚动条从 6px 压到 3px，透明度压到 9%，只在内容溢出时若隐若现
- 首屏文案压短一行、气泡上限从 486 提到 512，落地时第一条消息不再被上下裁掉

## 边界

- 玻璃的模糊半径是像素级固定值，窗口拉到很小（小窗 560×315）时对话面板本来就不显示（`body.mini` / `body.fs`），所以不存在"小窗口下拉伸出错"的情况
- 气泡里的数字、剧名仍然全部来自 core 的真实响应，这一版没碰任何逻辑
- 依然零模型、零常驻：关掉面板不动 DOM，不加载任何 ONNX/WASM
