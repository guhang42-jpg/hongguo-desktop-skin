# v1.025 — 详情页气氛底、播放页剧名卡、右缘集数队列

这版只动观感与顺手程度，播放链路、AI、外壳程序都没碰。三件事的参考对象是本机那套 Folia 音乐播放器（Electron 皮肤），搬的是它的取色和"正在播放"两块肌肉，没搬它的整屏歌词艺术字、3D 卡片排布、彩色胶片竖条。

## 改了什么

**1. 详情页不再是一块纯深色底**

打开任何一部剧，面板底色就是这部剧的封面 —— 放大 16%、模糊 44px、压低亮度后铺满整个面板，再盖一道自上而下 0.52 → 0.95 的深色渐变。换剧跟着换色（紫的仙侠、暖的宫斗、青的悬疑各不相同），描述文字与选集压在下半截，遮罩已经把它们护住。

**2. 播放页左上的剧名标签，变成一张迷你卡**

原来只有一行白字「第 110 集」。现在是一张卡：40×53 的小封面 + 剧名（单行省略）+ 副行「第 1 集 · 共 126 集」。跟返回钮同一条水平线、同一个视觉高度；顶栏一显形它就在，鼠标静置 3 秒和顶栏一起淡出。点下一集、点队列、点选集，卡上的集号即时改写。

**3. 播放页右缘一条竖窄集数队列**

一集一格，30×26 小方块，贴在窗口右边缘，左侧一道渐变过渡到底色。

- 平时收着：鼠标进到右缘 96px 内才浮出，移开 0.26 秒收回
- 当前集白底深字，看过的集格底一条 2px 橙色细线，长度按实际进度
- 悬停某格出一行小提示：「第 12 集 · 已看完 / 看过 66% / 第 7 集」
- 点一下直接 `playEpisode` 切集，不用回详情、不用开选集面板
- 队列自己把当前集滚到正中，126 集的长剧贴近右缘就看得到上下文
- 全屏下切集保持全屏（顺手修了切集会掉回剧场面板的老毛病）
- 鼠标静置、小窗挂机、摸鱼态都自动隐藏

## 已知边界

- 队列出现靠"贴边"，第一次用可能要找一下手感（鼠标怼到最右边就出来了）
- 封面糊底只取详情、播放页已有视频画面，所以主页不加（主页本来就有大 Hero）
- 队列里的橙色线是"看过多少"，没记下总时长的集不画线，不是漏了
- 不联网、不调模型、不截屏、不起后台服务，外壳 exe 本轮未重编（与 v1.024 同一个）

## 安装

解压后双击 `红果短剧.exe`。老版本直接覆盖不用卸载，剧库、收藏、观看进度都在 `%APPDATA%\HonggoDesktop`，不会丢。全屏播放只有声音没画面的机器，仍按顶栏提示装一次 HEVC 扩展。
