# v1.015 · 小果有了记忆，也开始会等人

> 三个词：**记得住、会等你、有分寸**。全程零联网、零模型调用、零截屏、零常驻轮询。

## 这版干了什么

以前的小果是个"每次见面都重新认识你"的助理：你昨天说过爱看修仙的，今天它照旧一脸陌生。

这版给它加了三样东西，全部落在 `ui/app.js` 里，没有新增进程、没有新增网络请求、没有装任何新依赖。

### 一、记忆：只记你真说过的话

不靠模型抽取，靠两条正则 + 去重累加：

```
我 / 咱 + (比较|特别|很|最)? + (喜欢|爱看|爱追|想看|只看|不看|讨厌|受不了|不喜欢) + ≤16 字
别 / 不要 / 不用 + (给我|再)? + (推荐|推|发) + ≤14 字
```

命中就存成一条事实，同一句再出现只把提的次数 +1。另外**真点开过哪部剧**也算记忆（点卡片 onclick 里 `touch("play")`）。

全部塞进 localStorage 的一个 key `xg.mem.v1`，装下偏好 24 条 + 提问记录 24 条 + 十来个计数，**整块不到 10 KB**。

- 问「你记得什么」→ 列出你自己说过的（带"几天前 / 提过几次"）、最近问过的、底部一行统计"2 条偏好 · 聊过 9 次 · 见过 7 回 · 全在这台机器的本地存储里，不联网"
- 说「忘了吧」→ 偏好、提问、亲密度、见面次数、今天聊过几次，一次全清，回一句"忘了。刚才那些都没了。"
- 同一句话不再在"最近问过的"里刷屏（新的提问会顶掉旧的同句）

### 二、陪伴：只在开面板那一下算一次，算完就睡

这版**没有定时器、没有后台轮询、没有截屏**。所谓"她知道什么时候该说话"，被降维成一次事件驱动的判断：

打开面板时按顺序问自己 ——

1. 第一次见面？→「我是小果 · 本机剧库助理。」
2. 今天已经聊过 5 次以上？→「又来了。」
3. 隔了 7 天以上没来？→「你有 N 天没来了。」
4. 隔了 3 天以上？→「三天没见着你了。」
5. 现在是凌晨 5 点前？→「这个点还没睡。」
6. 现在 23 点以后？→「又是这个点。」
7. 上午 11 点前？→「早。」
8. 熟到亲密度 ≥ 60？→「你来了。」

**同一种话一天只准说一次**（`MO.said` 记账，隔天清零）。所以你不会开开关关被它复读八遍。

开场白后面再挂两句，也是一天最多一次：

> 三天没见着你了。
> 我记得你说过「不喜欢太长的」。
> 你上次停在《徒儿对不起，功法是我瞎编的》第 98 集，还剩 28 集。

### 三、情感：不是生成的，是算出来的

没有 LLM 编情绪，就几个数字：亲密度 `bond`、见过几次、今天聊过几次。

- 开口 `+1`、说话 `+2`、真点开一部剧 `+3`
- 隔天不来按间隔扣，一次最多扣 4
- `bond` 分三档：< 25 生 / < 60 熟 / ≥ 60 亲

档位直接改观感：头像光晕从冷到暖（第 3 档是一圈 `rgba(255,120,80,.75)` 的橙光），球体的饱和度也跟着提。**情绪是可核对的两个数字，不是编出来的形容词。**

### 四、顺手修的两件小事

- **面板按内容收缩**：只开面板不问话时，以前固定 512 高、下面空一大片；现在按真实内容算高（头部 + 短语行 + 输入区按实际排版量，不猜），内容再多才封顶 512 转滚动。CSS 加了 `height` 过渡，伸缩是滑的
- **对话变长不再裁掉开场白**：`--ai` 不带 `--a` 时会自动问一句把面板滚到底，加了 `--noa`（`&noa=1`）联调开关跳过默认提问，才能干净验收开场白

## 跟 Miru 比，砍了什么留了什么

参考的是 `guhang42-jpg/Miru`（fork 自 `kiyotakali/Miru`），一个 Live2D 桌面宠物 + Flask 后端 + 三档 LLM API 的 AI 陪伴体，四类长记忆（projects / people / self / topics）+ 每日 journal + commitments + AttentionEngine（自己决定何时开口）+ Curator + SleepAgent（夜里整理记忆），大约 ¥2/天 token。

| | Miru | 小果 v1.015 |
|---|---|---|
| 记忆怎么来 | LLM 从对话 + 截屏里抽取、归类 | 两条正则抓你亲口说的偏好 + 真点开过的剧 |
| 记忆存哪 | 纯 Markdown，可打开核对 | localStorage 一个 key，面板里可看、一句「忘了吧」清空 |
| 何时开口 | AttentionEngine 30 秒一轮，屏幕内容变化才分析 | 开面板那一下算一次，算完就睡 |
| 情绪怎么出 | LLM 生成 + Live2D 表情 | bond / 次数几个数字驱动语气档位 + 头像光晕 |
| 夜里整理 | SleepAgent 半夜跑一遍 LLM | 不做 |
| 进程 / 联网 / 成本 | Python 后端 + 3 个 API + 每 30s 截屏 | 零进程、零 API、零截屏、零常驻 |
| 看你的屏幕 | 是（Vision 模型读截图） | **不看，一次都不看** |

结论：Miru 的"灵魂"是屏幕感知 + LLM 现场生成，这跟"零联网零 API 低功耗"是硬冲突的，抄不了。能抄的是**结构骨架** —— 记忆分事实、开口分场合、情绪分档位、一遍只算一次。骨架留下，里面换成确定性的零件。

## 实测

| 场景 | 结果 |
|---|---|
| 说「我爱看修仙的」 | 气泡底部多一行「记下了：爱看修仙的」，同时给 3 张修仙卡，语义单句 12 ms |
| 重启进程再问「你记得什么」 | 偏好、提问、统计全在 —— **WebView2 的 localStorage 跨进程持久化正常**（user data 目录在 exe 同旁 `红果短剧.exe.WebView2`） |
| `--mem --noa` 只开面板 | 三行开场白完整可见，面板高度收到约 215 px，无空白、无裁切 |
| 连问三句撑满 | 封顶 512 后转滚动，卡片可点 |

## 下一步没做的

- 小果关着的时候不会主动出声 —— 要做到得改 C# 侧托盘逻辑，这版不动
