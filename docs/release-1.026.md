# v1.026 — 圆钮化的小节工具、统一空态、Folia 式设置面板

这版只动界面结构与交互，播放链路、AI、外壳程序都没碰。三个参考点都来自本机那套 Folia 音乐播放器（Electron 皮肤）：小节标题右侧的 28px 圆形小工具钮、空态三件套（居中图标 + 一句话 + 一枚胶囊按钮）、设置页的分组导航 + 分组卡 + 底部版本区。

## 改了什么

**1. 小节标题右侧：一个圆钮顶掉一串字**

「继续观看」「热播榜」「为你推荐」三处原来的「收起」「展开全部」「换一批」文字按钮全部撤掉，换成 28px 圆钮：

- 一像素 `rgba(255,255,255,.13)` 细边、底色只加 5.5% 白，hover 提亮并放大到 107%，按下缩到 94%
- 图标 13px 线性 SVG：刷新 / 更多（›）/ 上下箭头，折叠方向用图标转 180° 表达，不用换字
- `align-self:center` + 上移 4px 抵消标题基线，圆钮与标题同一视觉中线，不再把标题行撑高
- 每颗都带 `data-hint`，气泡走 v1.024 那套自绘提示（「收起这块」「展开全部 15 部」「换一批推荐」）
- 「换一批」那颗 hover 时图标逆时针转半圈，一个动作一个反馈

**2. 空态三件套：图标 + 一句话 + 一枚胶囊按钮**

新增 `emptyBox()` 组件，三处直接套：

- 搜索没有结果 → 放大镜图标 +「没找到这部剧」+ 说明 + 胶囊「换个词搜」
- 「我的」页收藏为空 → 心形图标 +「还没收藏任何剧」+「详情页左边那颗 ♡ 点一下就在这里」+ 胶囊「去找剧」
- 「我的」页没有观看记录 → 播放图标 +「还没有观看记录」+「看一集就会出现在这里，进度也会记住」+ 胶囊「去发现」

样式：66px 圆形底（径向渐变 + 5% 白）、26px 图标、标题 14px/600、说明 12.5px 灰、胶囊按钮 `padding 9×20 / 圆角 999`，整块在容器里居中留白，不再是干巴巴一行灰字。

**3. 设置面板（照 Folia 那页排的）**

- 入口：顶栏右侧齿轮圆钮（与刷新 / 主题 / 摸鱼并列）
- 面板：宽 `min(620px, 94vw)`，从右滑入 0.34s，`z-index` 抬到播放容器之上（播放态打开也不会被压住）
- 左：132px 分组导航四组 —— 界面 / 播放 / 本机 / 高级，各带 15px 图标，选中项灰底高亮
- 右：标题 + 关闭 X + 滚动分组卡；分组卡 = 组名 + 行项（左标题、下说明灰字、右侧开关 / seg / 取值 / 按钮），行分隔线 5% 白
- `kbd` 快捷键用等宽字体小方块：`Space` 暂停 / `←→` 上下集 / `F` 全屏 / `D` 弹幕 / `R` 倍速 / `M` 静音 / `Esc` 退出
- 界面上真能改的：详情页封面糊底开关、热播榜默认收起开关、进播放页直接全屏开关、画面铺满（铺满 / 适应）、默认线路（高清完整 / 高清分段 / 标清完整）
- `Esc` 收起面板（捕获阶段拦，不影响播放页原有的分级 Esc）

**4. 底部版本块（这版的重点）**

照着 Folia 设置页底部那块排：

- 左：`v1.026` 大号 + 下挂构建号「1.026 · 2026-11-23 · main」（读同目录 `version.txt` / `build.txt`）
- 右：状态位（还没检查过 / 已经是最新 / 发现有新版 vX）+ 并排「重新检查」「打开下载页」
- 「重新检查」读 `version.json`（9s 超时，静默失败不打扰），比本机高就把状态位变橙；已经最新就弹一句「已经是最新版」
- 托盘那条更新气泡也会把远端版本记进面板，改完切过来状态位就是对的
- 「打开下载页」交给外壳打开（走 `postMessage({action:"openUrl"})`，外壳只放行 `https://github.com/` 前缀），不再只靠托盘气泡 + 手动开浏览器

## 顺手修的

- 分组卡作为 flex 子项被压缩，行高被吃掉、描述文字下半截被裁 —— 给 `.grp` 加 `flex:none`
- 行项右侧取值是等宽小字，宽度被挤到换行 —— 加 `flex:none` + 单行省略
- 设置面板 `z-index` 42 低于播放容器 50，播放态打开只露一条 —— 抬到 72，遮罩 71
- `renderMine` 里旧的空态块替换后多留一个 `}`，已清掉（`node --check` 通过）

## 已知边界

- 搜索的"零结果"在后端会被兜底成一组相关推荐，所以搜索空态多见于网络失败或筛选为空，不是每次打乱码都能看到
- 圆钮只有 28px，1360 宽窗口下看着克制，1920 全屏播放页不涉及（那几个钮只在首页与分类页标题行）
- 设置面板打开时左侧栏整体被遮罩压暗，与 Folia 一致
- 不联网、不调模型、不截屏、不起后台服务；外壳 exe 本轮未重编（与 v1.025 同一个）

## 安装

下载对应压缩包，解压到任意目录，双击 `红果短剧.exe`。首启会在 `%APPDATA%\HonggoDesktop` 起本地数据目录；保留旧目录即为升级。语义版多带 10 个模型文件，放 `ui\ai\` 下，小果会自己用。
