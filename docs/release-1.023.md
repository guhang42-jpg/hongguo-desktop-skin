# v1.023 — 播放页与详情页统一，选集提示不再挡按钮

> Windows 10/11 x64 · 壳 + 前端 + 本地 core，不联网、不调模型（语义版仅本机推理）

## 这版改了什么

### 1. 播放页左条统一成详情页那套

- 宽度 58 → **64**，与详情页 `.srail` 同尺寸：52×52 按钮、18px 图标、右缘 `inset -1px 0 0` 分隔线
- 去掉右侧 18px 圆角，改直角（与详情页一致，也不再是"手指"造型）
- **不再整条铺开**：剧名 + 集数改成浮标签，只在鼠标压住返回钮时浮出；标签起点 70px，不压按钮
- `vTitleOf` 回归全名：竖排时代"超过 9 字截断 + title 兜底"的逻辑删掉，整条剧名一次给全

### 2. 选集提示改成"就地信息行"

- 悬停某集时，`选集` 标题行右端直接从「共 126 集」变成橙色「第 105 集」；有进度时是「第 110 集 · 上次 0:16」
- 不再弹浮层：浮层无论放上、放右都会压住相邻集数格，索性改成零遮挡的信息行
- 集数格自带 hover：底色提亮 + 边框加亮 + 上浮 1px，反馈留在手指底下

### 3. 顺手修的三个 bug

- `.eptip` 样式误嵌进 `.toast` 声明块中间，顶部灵动岛提示（"已收藏"这类）整条失效 —— 拆成独立规则
- `#epTip` 节点原来排在 `<script>` 之后，`$("#epTip")` 拿不到元素，事件绑定直接 return（这也是浮层一开始完全不出现的原因）—— 节点移到脚本之前
- 悬停浮标签（`.vtitle` / `.srail .sr b`）在 64px 容器里被"可用宽度"压成一百来像素，长剧名被省略号吃掉 —— 加 `width:max-content`

### 4. 交互细节

- 换一部剧时详情内容滚回顶部；同一部剧再次打开保持原来的阅读位置
- 播放页左条改直角后，与详情页左条在圆角、分隔线、按钮尺寸上完全对齐

## 已知边界

- 选集段按钮（`1-24 / 25-48 / …`）暂时没有悬停说明，段内集数本身足够定位
- 主界面左侧抽屉展开态（196px）仍会压住主内容左边缘约 128px，尚未改成浮标签
- 剧名浮标签在窗口特别窄时可能贴近画面中央，暂未做右边界避让

## 校验

真机 1360×880 与 1920×1080 全屏各截一轮：选集悬停「第 110 集」、未看「第 105 集」、播放页剧名浮标签完整、顶部提示条恢复。
