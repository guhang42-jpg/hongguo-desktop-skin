# 红果短剧 · 桌面皮肤版 v1.024

发布日期：2026-11-23
上一版：[v1.023](https://github.com/guhang42-jpg/hongguo-desktop-skin/releases/tag/v1.023)

这一版只动界面和交互，没碰播放链路、没碰 AI 引擎：外壳 `红果短剧.exe` 与 `core/hongguo-tv-core.exe` 和 v1.023 是同一个二进制，只换了 `ui/app.js`、`ui/index.html`。

## 改了什么

### 1. 主界面左条：不再整条铺开，只弹单项浮标签

上一版主界面左条悬停会把整条铺成 196px 抽屉，把左侧内容压掉一大块。这一版固定 68px 不动，鼠标压到哪一项，就在那一项右边浮一个小标签：

- 发现 / 找剧 / 榜单 / 我的（四项导航）
- 品牌名（压在 logo 上时浮出）
- 小果 · 本机助理（压在球上时浮出）

浮标签跟按钮同一行、靠右 62px 起、移开即收；`aside` 本身不再改宽度，主内容区一次都不会横跳。

### 2. 详情页底部：补上「看完这集，再看看」

长剧详情页在选集下面原本空着一大条。现在按本机剧库做同类推荐：

- 打分：题材标签重合 ×2 + 内容类型相同 +1，其次按最近播放 / 收藏时间
- 取 6 部，2 列 3 行横向小卡（44×59 封面 + 剧名 + 前两个题材）
- 不足 2 部就不显示，避免出现孤零零一条
- 点卡直接换剧打开详情；换剧时这块会先清空，同剧再开保持阅读位置

### 3. 段按钮就地报数

压住「97-120」这类分段按钮时，选集标题行右端从「共 126 集」变成：

```
第 97-120 集 · 看过 1/24 · 看完 1
```

`看过` 是该段有进度记录的集数，`看完` 是播放位置已到尾部（≥96%）的集数。压住单集仍然显示该集自己的状态。

### 4. 看过的集：格底一条细线

按 `hg_resume_v1` 里存的「当前秒 / 总时长」算比例，画 2px 暖橙底边线（6%–99%，看完画满）。两个防呆：

- 播放位置 < 5 秒的不算（刚点开就退不算看过）
- **没记下总时长的一律不画**——这条是修 v1.024 开发过程中的一个坑：早期版本用「有记录就算 40%」，结果整片选集 24 格全挂橙线

同时把 `.ep.seen` 的整圈橙色边框和橙色数字改回中性灰，橙色只留底边那一条，避免整屏发橙。

### 5. 播放页底栏图标化

- 「选集」文字 → `▦`，提示里写「选集：按段翻到想看的那一集」
- 「铺满 / 原比例 / 拉伸」三态 → `▭ / ▤ / ⤢`，当前是哪一种写在提示里（状态不再靠文字占宽）

### 6. 系统 tooltip 换成自绘

Windows 那个灰白系统提示框慢、不能换行、样式跟界面完全不搭。这一版：

- 启动时扫一遍 `[title]`，文字转进 `data-hint` 并摘掉原生 `title`
- 鼠标移入时在光标右下 14/18px 显示深色气泡（可换行、跟随、出界自动翻边）
- 左条那几项本来就弹浮标签，不重复再弹一次
- 滚轮 / 按下时自动收起

### 7. 首屏骨架屏

剧库接口没回来之前，推荐区先摆 6 张会呼吸的灰卡（渐变扫光 1.6s 一轮），不再是一片空白干等。任何渲染函数重填 `#grid` 就自动消失。

### 8. 小窗播放里点开详情，自动还原窗口

小窗是独立形态，详情面板一开就压住整个画面。现在在小窗播放中点开详情会先 `setMini(false)` 回到常规窗口，并给一句「已退出小窗，方便看详情」；单纯从「继续观看」恢复播放（播放器还没起来）时不触发，避免来回抖。

### 顺手修的

- 「继续观看」卡片：渐变底加重（36%→68%→90%），信息行加文字投影，长剧名压到封面亮部上也能读清；数字用等宽字形
- 左条激活态：整块橙色渐变 → 灰底 + 1px 浅描边 + 橙色图标，一条上不再同时挂三个橙块

## 已知边界

- 底部推荐只从**本机已加载的剧库**里挑，不做联网推荐；库里同类不足 2 部时这块不显示
- 骨架屏只在冷启动第一次加载时可见（本机接口通常 < 1s，多数人看不到）
- `--jump <series_id>~<集号>` 这个联调参数仍在正式包里，未写进 README
- 「小窗点开详情自动还原」只覆盖播放中的情况；小窗里从剧库浏览（播放器未起）时不打断

## 安装

下载 `hongguo-skin-1.024-win64.zip` 解压直接用（轻量版，AI 面板会提示装不上模型但仍可用关键词检索）；想用小果的语义检索就用 `hongguo-skin-1.024-win64-ai.zip`（25.4 MB，含 `ui/ai/*` 10 个文件）。

首次启动 WebView2 会用到系统自带的 Runtime，Win10/11 一般已预装；缺的话装一次 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
