## 红果短剧 · 桌面皮肤版 v1.001

首个对外版本。官方核心一个字节没动，只把界面重做了一遍。

### 下载

- `红果短剧-1.001-win64.zip`（约 6.6 MB，解压即用）
- 解压后双击 `红果短剧.exe` 即可，需要 WebView2 Runtime（Win10/11 一般自带）

### 这版有什么

- 整套界面重做：左栏固定导航、胶囊标签、大 Hero、继续观看横滑、热播榜带名次、推荐瀑布流、底部悬浮播放条
- 整窗毛玻璃 + 深空底色统一，窗口直角利落，去掉了透明度档位
- 幽光 / 星空 / 流星 / 光尘动态背景，按剧的类型换配色，播放时更活跃，鼠标视差
- 剧场模式：打开不抢全屏，视频待在面板里，⛶ 才是真全屏
- 小窗模式：430×780 置顶、半透明沉浸、控件自动收起
- 画面三档：原比例 / 铺满裁剪 / 拉伸；控制条一行排开不换行
- 播完 5 秒「即将播放 第 N 集」倒计时，可立即 / 取消
- 等级 + 45 个成就的小成长系统（本地存档）
- 新 App 图标（含任务栏多档）

### 修复

- 换集时错误续播上一集进度，导致"一开场就播完"的自动乱跳集
- 剧场面板左边留 14px 缝，播放时能看见底下的页面
- 窗口左上角圆角过大、顶部色带割裂
